🧠 Psicólogos Net — Plataforma de Perfiles Profesionales

Sitio web profesional desarrollado con Astro y TailwindCSS, enfocado en brindar presencia web accesible a psicólogos y profesionales de la salud mental que están iniciando su práctica o que actualmente solo cuentan con redes sociales.
El proyecto permite mostrar múltiples perfiles profesionales, con información clara, opción de contacto directo y un diseño limpio, humano y confiable.
Pensado como un template escalable y de bajo costo, con mantenimiento continuo de perfiles.  
El proyecto cuenta con tres secciones principales: **Inicio**, **Sobre Nosotros** y **Blog**, ofreciendo una navegación fluida, diseño responsive y un enfoque claro en la presentación de servicios legales.

🎯 Objetivo del Proyecto

* - Dar presencia web profesional a psicólogos que inician su práctica

* - Ofrecer una alternativa más confiable que solo redes sociales

* - Mantener costos bajos mediante una estructura reutilizable

* - Facilitar contacto directo entre paciente y profesional

* -Permitir mantenimiento y actualización sencilla de perfiles

## 🧰 Tecnologías Utilizadas

- **Astro** — Framework principal para la construcción del sitio
- **TailwindCSS** — Estilos responsivos y diseño moderno
- **Netlify** — Hosting y despliegue continuo
- **Markdown / MDX** — Estructura de los artículos del blog
- **JavaScript / TypeScript (opcional)** — Lógica ligera de interacción
